  • • Unverifiable by Machines: A computer cannot mathematically parse or check "Wait, let me rethink step 2..." without another fuzzy LLM prompt.

  • • Formal Proof Object: Every line is an Abstract Syntax Tree (AST) verified deterministically by SymPy or Z3 solver in <1ms.
